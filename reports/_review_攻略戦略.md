# レッドチームレビュー：『高速道路6社 情報系攻略戦略』v1

- 対象：reports/高速道路会社 情報系 攻略戦略.md（2026-10-03）
- 照合元：ホワイトスペース調査 v2
- 視点：P1＝情報システム部長、P2＝契約・法務・人事部長、P3＝SIer営業本部長

## 総評

スコープ（管理部門×物品・役務）と現場知見はよく反映されています。H1〜H8の点数・判定もv2と一致しており、転記ミスはありません。ただし、このままでは**面談が取れず、取れても「情報収集に来た業者」と見られます**。原因は次の4点です。

1. 首都高を不祥事の直後に最優先とし、公取委の措置を選定理由に挙げている。
2. 「管理費圧縮」という価値メッセージが、高速道路の会計とずれている。
3. 評価基準のすり合わせ、更新時期の質問、無償PoCなど、調達の公正性に触れる手順が残っている。
4. 初回面談の獲得方法と、予算サイクルへの合わせ方がない。

使う前にC1〜C6を直してください。

## Critical（必ず直す）

**C1 首都高の優先度と不祥事の扱いが矛盾**（0章の優先表、2-1「選んだ理由」、H2の根拠）
- 問題：4-5は「不祥事を売り込みに使わない」と定めているのに、2-1は公取委の改善措置要求を首都高の選定理由に挙げ、0章はH2を持参カードにしています。措置1年目の契約・総務部門は、業者との接触を最小限にするのが普通です（P2）。さらに、DX推進室は内製の講師で利用者を22人から224人に増やしたと自ら発信しており、H1の偽シグナル「内製チームあり」に当たります（P1）。
- 修正：
  - 2-1の選定理由から公取委を削除し、注意欄だけに残す。
  - 首都高には2026年度中はH2を持参しないと明記する。
  - H1を「224人の次：規程参照（RAG）とAIガバナンス」に差し替える。
  - 優先1位をNEXCO東日本にし、首都高は2位（DX推進室向けの単独テーマのみ）とする。

**C2 「管理費圧縮」が会計とずれている**（0章、1-2 T1、5-3）
- 問題：「管理費用2,390億円」は道路の維持修繕・料金収受などの費用で、本社管理部門の経費ではありません。償還主義では料金に利益を含めない設計なので、「赤字だから圧縮」という言い方は経理部長から素人と見られます（P2）。「6社とも料金収入は過去最高で赤字・薄利」も出典は2社分しかなく、【事実】ではなく一般化です。
- 修正：
  - T1を「担い手不足のもとで、増え続ける更新事業の事務を限られた人員で回す」に書き換える。
  - 効果の指標は、削減時間、属人化の解消、処理リードタイムにする。
  - 管理費の記述は【仮説】として背景に移す。

**C3 調達の公正性に触れる手順**（4-1「提案前」、H1・H2の検証質問、2-3の情シス「聞くこと」、4-3 C）
- 問題：
  - (a) 「評価基準のすり合わせ」は仕様の誘導にあたります。
  - (b) 「電子契約の次の更新時期」「端末・ライセンスの更新時期」「次年度予算に生成AIの項目はあるか」という質問は、4-5が禁じる公告予定案件の情報にあたります。
  - (c) 上流（診断、中計KPI）を受託すると、後の入札に参加できなくなる場合がありますが、その考慮がありません。
- 修正：
  - (a)を「調達方式と時期を相手の規程に従って確認する（評価基準には関与しない）」に改める。
  - (b)は面談で聞かず、公表済みの発注見通しや公告で確認する。
  - (c)は5-2に「上流を受託する前に、後の入札への参加制限の有無を確認する」を加える。

**C4 PoCとデータの扱いが自己矛盾**（O2・O3、4-5「非公開資料」）
- 問題：O2の「契約済み書類」は非公開資料で、4-5のNGとぶつかります。O3の規程RAGは、社内規程がなければ成立しません。有償か無償かも書かれていません。無償の役務提供は、特殊会社では利益供与や後続の随契の公平性の問題になります（P1・P2）。
- 修正：次のように明記する。
  - PoCは有償とし、契約後に顧客環境（テナントまたは閉域）で実データを使う。
  - 契約前のデモは、公開資料（公告、入札説明書、公表済みの規程）だけで行う。
  - 無償で出すのは論点メモまでとする。

**C5 接待・贈答の扱いが弱い**（4-5、7-1）
- 問題：「倫理規程を持つ可能性」と書かれているだけです。高速道路株式会社法には役職員の収賄罰則があります（条文は要確認）。首都高は措置への対応中で、業者との面談の記録が義務化されている可能性もあります。
- 修正：リスクを「刑事罰」に格上げし、7-1に自社ルールとして次を加える。
  - 面談は先方の会議室で、2名以上で行い、議事メモを保管する。
  - 首都高ではOB・再就職者経由の紹介を使わない。

**C6 90日計画の終盤が予算サイクルと年末に重なる**（0章、6-1の第12〜13週）
- 問題：2027年度予算は10〜11月に部門内で固まるのが通例で、事業計画には国交大臣の認可も要ります。12/21〜1/8の提案では予算に間に合わず、しかも年末年始です。また、紹介のない新規ベンダーの初回面談は、獲得までに4〜8週かかるのが普通です。第3〜6週に6〜9件という目標は現実的ではありません（P3）。
- 修正：
  - 目標を「2027年度の年度途中の少額役務、または2028年度予算への仕込み」に変える。
  - 第3〜6週は「面談の依頼を出し、2〜4件を実施」とする。
  - 提案は12/18までに前倒しする。
  - 各社の予算の締め切りを★★★の確認事項に加える。

## Major

**M1 質問バンクが長すぎる**（4-3）
- 質問は28問あり、さらに深掘りの質問が付いています。60分の面談（実質40分）で聞けるのは8問程度です。相手ごとに「必ず聞く5問」を冒頭に置き、残りは予備にしてください。
- 情シス向けの例：
  1. 生成AI・SaaSで今いちばん困っていること
  2. SaaS審査の手続と期間
  3. NSSとの役割分担（事実の確認のみで、批判はしない）
  4. 同じ悩みを持つ他部門の紹介
  5. 次に何をお持ちすればよいか
- 予算と資格の質問は初回から外します。資格区分は自分で調べてください。相手に聞くと宿題を出すことになります。

**M2 オープニングが情報収集に聞こえる**（4-2）
- 「仮説の確認に来た」では、相手の時間をただで使うことになります。相手に渡す価値のある資料を用意してください（他のインフラ企業での生成AI定着の型、統一基準の要点1枚）。
- 書き換え案：「他のインフラ企業で生成AIを定着させた要点を1枚にまとめてお持ちしました。御社に当てはまるか、ご意見をいただけますと幸いです」

**M3 T2（契約事務）が未検証の前提のまま柱になっている**
- 現場知見では、工事はLOBが発注します。契約・積算システムもLOBかグループ会社の所管かもしれません。
- 45日判定に「契約部門が管理部門に属し、契約事務のシステム予算を持つか」を加え、×ならH2を降格してください。

**M4 監査室を「トップダウンの営業ルート」として扱っている**（2-3）
- 内部監査は独立性が前提で、ベンダーの推進役にはなりません（P2）。「要件の出し手。接触は情シス経由」に改めてください。

**M5 NSSとの関係が楽観的**（5-4、O4・O5）
- NSSは中長期IT企画とセキュリティ規程の見直しを担っています（v2 2-3）。O4・O5はその本業と正面からぶつかります。
- 現実的なのは共同提案ではなく再委託です。初年度は「NSSの協力会社に登録して再委託を受ける」を主ルートとし、直接提案は研修とSaaSに限ってください。
- NSSが西日本も担当しているか（2021年以降は情報テクノロジー社が担当）も確認が必要です。

**M6 Go/No-goとKPIがあいまい**（6-3）
- 「全社で不要と言われた」の「全社」が1社なのか6社なのか不明です。会社単位で判定してください。
- 資格は通常取れるので、No-goの基準として機能しません。実際に効くのは等級と時期です。
- KPIに金額、CRMの確度ステージ、紹介数、2回目面談への転換率を加え、「受注見込み」がどのステージかを定義してください。

**M7 90日で攻める会社が多い**（0章、6-1）
- 5社に並行して当たると、どれも薄くなります。主攻をNEXCO東日本、副攻を阪神（SaaS導入の実績あり）に絞ってください。首都高はDX推進室の単独テーマだけにします。

## Minor

- **m1** 【事実】に推論が混じっています。該当は2-1の「次期中計を策定中と推定」、東日本の「窓口が明確」、H8・2-1の「確認できず」「見当たらない」です（最後の2つは検索範囲の限界にすぎません）。いずれも【仮説】または【未確認】に改めてください。
- **m2** 凡例にないラベル（【一般知識・要確認】【仮説に基づく方針】）は、凡例に足すか既存のラベルに統一してください。
- **m3** 6-2・H7の「統一基準 10/1施行予定とされた」は、10/3時点では施行済みのはずです。確認して更新してください。首都高PCリースの更新時期も、v2の「2025〜2026年度」と揃えてください。
- **m4** H5・4-3Dの「認可手続の書類」は、経営企画や事業部門の所管である可能性が高く、法務に聞くと的外れです。
- **m5** 4-3Fの「対象外という整理で終わりましたか」は誘導的です。「統一基準をどう扱うご方針ですか」に変えてください。
- **m6** 首都高の窓口である技術部DX推進室は、定義上C'(b)の条件付きスコープです。0章の表に注記してください。
- **m7** v2 9-3の「改善措置要求への対応として提案2」は本書の方針と逆です。本書がv2を上書きすることを冒頭に明記してください。
